
# KALI SETOOLKIT

Ferramentas de varredura, exploiting e cracking para uso em sistemas e web.



## 📦 Instalação

### 🧬 Clonando o projeto
Inicie clonando esse projeto em sua máquina:

```bash
  git clone https://github.com/GabSouzaGit/kali-setoolkit
  cd kali-setoolkit
```

### 🏠 Ativando o ambiente virtual
Antes de tudo, insira:
```bash
  python3 -m venv .venv
```

E então, execute o arquivo de ativação da pasta .venv

- Para usuários Windows:
```bash
  .venv\Scripts\Activate.ps1
```
Ou apenas clique em "activate-venv.bat".

- Para usuários Linux/Mac/Kali:
```bash
  source .venv\bin\activate
```

### 🚀 Atualizando pip
Em seguida, atualize o pip (se necessário):
```bash
    python -m pip install --upgrade pip
```

### 📃 Baixando dependencias do .toml
E por fim, baixe as dependências:
```bash
    pip install -e .
```
